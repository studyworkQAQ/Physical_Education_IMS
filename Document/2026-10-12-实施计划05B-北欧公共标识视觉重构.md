## 1. 目标与非目标

**目标**：把《田径场年鉴》整体换成**北欧公共标识**（Nordic public signage）—— 参照斯德哥尔摩地铁 / 丹麦铁路 / 宜家说明书那一族的气质：**扁平、无纹理、无渐变、严格网格、充足留白、图形符号优先于装饰、色彩克制到一个主蓝 + 三个语义色**。

**非目标**
- ❌ **不动任何业务逻辑、不动 API 层、不动数据形状**。⚠️ **具体清单（一个字节都不许改）**：`src/api/**`（`client.ts` / `endpoints.ts` / `types.ts` / `contract.ts` / `auth.ts` / `expiry.ts` / `generated/schema.d.ts`）、`src/catalog/resources.ts`、`src/present.ts`（**中文标签的唯一所有者，141 个列名标签**）、`src/stores/**`、`src/router/index.ts` 的**守卫逻辑**（可以改它引用的组件，不能改判据）、`backend/**` 全部。
- ❌ 不引入任何新依赖（**UI 库 / 图表库 / 字体图标库一律不要**）。⚠️ Plan 05A 刚做到「前后端新增依赖都是 0」（用 CDP + Node v24 全局 `WebSocket` 代替了 Playwright），**这个纪录要保住**。
- ❌ 不改响应式断点矩阵（仍是**学生端 375px / 教师端与管理台 1440px** 两档）。
- ❌ 不做暗色主题（用户要「浅色系」）。

## 4. 验收（每一条都要可执行）

### 4.1 ⚠️「不能出现文本内容重叠」要做成机器守卫（本计划的唯一新增守卫）

**这是用户 7 条要求里唯一能机器判定的**，故**必须做成守卫，不能只靠人眼看截图**。

**做法**：在 `smoke.mjs` 的 DOM 取证那一步（第 14 步，**已是 CDP 姿势**）里，对 15 条路由各注入一段脚本：
1. 取全部**含文本的叶子元素**（`TreeWalker` 过 `NodeFilter.SHOW_TEXT`，取每个非空文本节点的 `parentElement`）；
2. 对每个元素取 `getBoundingClientRect()`，**过滤掉零面积与 `visibility:hidden` / `opacity:0` 的**；
3. **两两求交**，若交集面积 > **两者中较小者的 20%**，且**两者不是祖先-后代关系**（嵌套是正常的），则判为重叠；
4. 输出**每一处重叠的**：两个元素的 `tagName` + 各自文本前 20 字 + 两个 rect。

⚠️ **谓词要先对已知反例验证**（硬规矩 #107）：**先造一个故意重叠的最小页面**（例如两个 `position:absolute` 的 span 叠在一起），**断言守卫会报它**；再对真实页面断言报 0 处。**没有第一拍，「0 处」可能是谓词根本不会命中任何东西**（这正是 Plan 03 终审查出的「用 `app.routes` 写的路由遮蔽扫描是假绿的」那一族）。
⚠️ **`--force-prefers-reduced-motion` 仍要加**（若 §3 决定保留数字滚动）；**若删掉了滚动，这一条可以在报告里写明「已不需要」** —— 但**`--dump-dom` 得到 0 字节**与 **Vite 只绑 `::1`** 那两个坑仍在（前者已随 CDP 改造消失，后者要核实）。
⚠️ **溢出容器也算「排版不干净」**：额外加一拍 —— **断言没有任何元素的 `scrollWidth > clientWidth + 1`**（横向溢出），**且 `document.documentElement.scrollWidth <= window.innerWidth`**（整页无横向滚动条）。⚠️ **大屏在 1440px 下今天就不该有横向滚动**（Plan 04 Task 3 的验收里有这一条），**学生端在 375px 下同理**。

### 4.2 其余验收

1. **`npm run build` 退出码 0**，**0 个 `@ts-ignore` / `@ts-expect-error` / `as any`**（Plan 05A 的纪录是 0，**不许退步**）。
2. **`npm run check:tokens` 绿**（换肤后仍然一个散落色值都没有）。⚠️ **它的反空转断言是「`tokens.css` ≥20 处色值」** —— **换肤删掉一批令牌后可能不足 20 处**，**那就把下界调到实测值并说明**（不要为了让它绿而塞无用的令牌）。
3. **`npm run check:dist` 绿**（`dist/` 里 grep 不到 `adoptFromUrl`）。
4. **`smoke.mjs` 退出码 0、17 步全绿**（**加了 §4.1 的重叠守卫之后仍要全绿**）。⚠️ **第 14 步的 DOM 断言里有页面标题文字**（例如大屏那几个英文小标题 `ALERTS` / `LAYERS` / `THIS WEEK` / `CHECK-IN`，它们是为窄体全大写拉丁小标题设计的）→ **换成北欧标识方向后它们大概率要改成中文或改大小写**，**那会让一部分断言变红**。**按硬规矩 #88：先跑一次全量、把红掉的逐个收进来，不要只 grep 那个字符串。**
5. **对比度实测**：浅底上的全部前景/背景组合逐个算对比度，**正文 ≥ 4.5:1、≥18px 或粗体 ≥ 3:1**（WCAG AA）。**把实测表写进报告**（Task 3 曾给出 26 对的表，照它的形状）。
6. **截图**：15 条路由各截一张（学生端 375px、教师端与管理台 1440px），存进 `Document/`，**文件名用 ASCII**（Plan 04 Task 5 的教训：PowerShell 5.1 读无 BOM UTF-8 的 `.ps1` 会写坏中文名）。⚠️ **控制者会人眼复核这批截图** —— 它们是「像不像北欧公共标识」的唯一判据。
7. **后端一字未改**：`git diff <起点> HEAD -- backend` **为空**；后端 **1333 passed** 仍成立；四个指纹 + 18 个模板指纹逐字不变；`Test-Path backend\pe.db` 是 `False`；`data/seed/` 0 文件。
