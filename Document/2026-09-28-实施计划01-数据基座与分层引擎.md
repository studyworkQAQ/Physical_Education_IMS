# 计划 01：数据基座与分层引擎 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立后端骨架、数据模型、高保真仿真数据与每日批处理管道，跑通「原始体测数据 → 国标得分 → 校内百分位 → 短板/体成分/趋势 → 红黄绿分层」全链路，500 人逐人可追溯。

**Architecture:** 模块化单体 FastAPI。`domain/` 为无 I/O 纯函数层，承载全部研究结论（评分表、短板判定、分层规则）；`pipeline/` 按业务日期幂等编排；`adapters/` 通过 `DataSourceAdapter` 接口隔离乐跑数据源，使未来接真实只读接口的改动限于单个实现文件。SQLite + SQLAlchemy，Repository 模式封装持久化。

**Tech Stack:** Python 3.11+、FastAPI、SQLAlchemy 2.x、pandas/numpy、pytest、SQLite

**Spec:** `Document/2026-09-28-体育闭环原型-设计spec.md`

## Global Constraints

- Python **3.11+**；数据库为 SQLite 单文件 `backend/pe.db`；ORM 为 **SQLAlchemy 2.x**
- `app/domain/` 层**禁止任何 I/O**：不得 import `sqlalchemy`、`fastapi`、`requests`，不得调用 `open()`、`datetime.now()`、`random` 无种子接口；时间与随机数一律由调用方注入
- 指标口径（spec §4.2，**决定 `W` 的分母**）：**8 项原始测量 → 7 个国标计分项（身高体重合成 BMI）→ 6 个短板判定项（排除 BMI）**。BMI 不计入短板，避免与体成分维度 `C` 重复计数
- 国标评分依据《国家学生体质健康标准（2014 年修订）》
- 百分位分组维度：**同校区 × 同性别 × 同龄组**；必须物化为 `percentile_snapshot`，**禁止实时计算**
- 幂等键：`(semester_id, business_date)`，在 `daily_sync_run` 上为唯一约束
- `valid_count < 4`（共 6 个短板判定项）→ 本日不分层，标签置 `insufficient_data`
- 分层规则共 **7 条**：`R1 R2 Y1 Y2 Y3 Y4 G1`，按优先级**命中即停**，全部命中规则 ID 落库
- 仿真数据由单一 `--seed` 驱动，默认 **`20250828`**；同 seed 输出**字节级一致**
- 目标分层分布默认 **红 20% / 黄 45% / 绿 35%**，容差 **±5%**
- 体成分异常 `C` 阈值：体脂率 **男 > 20%、女 > 28%**，或肌肉量 **< 同龄同性别 P20**
- 骨骼肌指数**第一批不参与** `C` 判定（入库但不判定）
- 趋势标签仅作**升级项，永不降级**（规则 Y4）
- 500 人批量管道回放 **< 60 秒**
- 代码注释、commit message、用户可见文案一律**中文**
- 每个 Task 结束必须 commit；禁止跨 Task 累积未提交改动

## Review Focus

spec 隐含但任务测试容易漏掉的五类输入与失效模式，按最可能伤到使用者的顺序排列。每条已在所属 Task 中落地为具体测试。

1. **国标评分表分段边界值** — 如 1000 米跑恰好等于某档阈值秒数时，应取该档得分，不得因浮点误差掉档 → Task 2 `test_score_at_segment_boundary`
2. **单项缺失导致 `valid_count` 变化** — `W` 必须按有效项计，缺失项**绝不当 0 分**；`valid_count < 4` 时不分层 → Task 8 `test_missing_item_not_counted_as_zero`、Task 9 `test_insufficient_data_when_valid_count_below_4`
3. **量纲错误**（身高录成 `1.75` 米而非 `175` 厘米）— 应启发式识别、×100 修正并写 `cleaning_log` → Task 5 `test_unit_error_height_in_meters_normalized`
4. **某性别龄组样本 < 30 人** — 百分位不可靠，应降级到国标常模并标记 `percentile_source = national` → Task 7 `test_snapshot_falls_back_to_national_when_sample_below_30`
5. **同业务日期重跑** — 派生数据必须完全一致且无重复行 → Task 10 `test_rerun_same_business_date_is_idempotent`

```python
from app.domain.indicators import (
    Sex, ScoredItem, WEAKNESS_ITEMS, ITEM_BUCKET,
    age_group_of, score_item, raw_from_score,
)

def test_weakness_items_exclude_bmi():
    assert len(WEAKNESS_ITEMS) == 6
    assert ScoredItem.BMI not in WEAKNESS_ITEMS

def test_scored_items_count_is_seven():
    assert len(list(ScoredItem)) == 7

def test_buckets_cover_all_weakness_items():
    assert {ITEM_BUCKET[i] for i in WEAKNESS_ITEMS} == {
        "endurance", "strength", "speed_flexibility"}
    assert ITEM_BUCKET[ScoredItem.BMI] is None

def test_direction_is_normalized_to_higher_is_better():
    # 50 米跑越快得分越高
    fast = score_item(ScoredItem.SPRINT_50M, 6.5, Sex.MALE, age_group_of(19))
    slow = score_item(ScoredItem.SPRINT_50M, 9.0, Sex.MALE, age_group_of(19))
    assert fast > slow

def test_score_at_segment_boundary():
    # Review Focus #1：恰好等于档位阈值时不得因浮点误差掉档。
    # 阈值从评分表本身取，避免硬编码魔数与 CSV 内容脱钩。
    from app.domain.indicators import segment_thresholds
    thr = segment_thresholds(ScoredItem.SPRINT_50M, Sex.MALE, age_group_of(19))[3]
    at_thr     = score_item(ScoredItem.SPRINT_50M, thr, Sex.MALE, age_group_of(19))
    just_worse = score_item(ScoredItem.SPRINT_50M, thr + 1e-9, Sex.MALE, age_group_of(19))
    assert at_thr == just_worse
    assert at_thr is not None

def test_sex_specific_items_differ():
    m = score_item(ScoredItem.PULL_UP_OR_SIT_UP, 10, Sex.MALE, age_group_of(19))
    f = score_item(ScoredItem.PULL_UP_OR_SIT_UP, 10, Sex.FEMALE, age_group_of(19))
    assert m != f  # 男引体向上 10 次与女仰卧起坐 10 次得分不同

def test_missing_value_returns_none():
    assert score_item(ScoredItem.VITAL_CAPACITY, None, Sex.MALE, age_group_of(19)) is None

def test_raw_from_score_roundtrips():
    for item in WEAKNESS_ITEMS:
        raw = raw_from_score(item, 80, Sex.MALE, age_group_of(19))
        assert abs(score_item(item, raw, Sex.MALE, age_group_of(19)) - 80) <= 1
```

- [ ] **Step 3: 实现潜变量模型（spec §10.2）**

```text
latent_fitness    ~ N(0, 1)
latent_endurance  = 0.8·latent_fitness + N(0, 0.6)
latent_strength   = 0.7·latent_fitness + N(0, 0.7)

BMI 得分           = 由身高体重分布独立生成后正查评分表
各项原始值         = raw_from_score(得分, 性别, 龄组)
```
