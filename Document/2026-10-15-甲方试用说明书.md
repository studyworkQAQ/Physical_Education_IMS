# 厦大体育数智系统 · 甲方试用说明书

> 2026-10-15 · 给体育教研室的老师、教务干事与信息中心读的一份「点开就能用」的说明。
> ⚠️ **开始试用之前请先读第 6 节「须知」**（前四条关系到数据与隐私）。
> 逐字的技术口径不在这里，在随附的《技术方案与实施基线》（下称 **spec**，给开发者与对接工程师读）；本文需要指细节时只给指针，不复述。

## 1. 这是什么

一套「**数据驱动 → 智能处方 → 智慧反馈**」的闭环原型：学生的体测、体成分与乐跑数据进来 → 按规则把人分成红 / 黄 / 绿三层 → 为每人生成一份**可解释**的周训练单 → 再把课堂快评、每日打卡与二次小测收回来 → 触发预警、给教师弹降量建议、给学生推站内消息。
本次试用跑的是**高保真仿真数据**：60 名学生的姓名、学号、体测成绩全部由生成器造出，全流程已经跑通。
⚠️ **它不是生产系统**：没有接任何真实数据源、没有真实推送（微信 / 短信一律没有）、不做口令找回。它今天的两个用途是：让教研室看见这套闭环长什么样，以及作为与乐跑工程团队谈对接的**技术依据**。

## 2. 三条打开方式

### ① 我方提供的公网链接（最省事，任何网络都能开）

链接的形状是 `https://<随机三段单词>.trycloudflare.com`（每次重开都变，所以本文不印某一条具体地址）。由我方发给你们即可。
⚠️ **链接的寿命 = 我方那台机器上隧道进程的寿命**：进程一停，链接立刻失效。失效有**两种样子**，而它们意味着同一件事：① 打开是 Cloudflare 自己的一页英文错误；② 浏览器直接说「找不到服务器」（那个地址已经被收回了）。⚠️ **两档都不会自己恢复**（我方那台机器上的脚本**刻意不自动重开** —— 自动重开会换掉你们手上那条链接），一律找我方重开；重开之后是一条**全新的地址**，请把它重新发给试用的人。

我方自己开一条是这样（两个终端，都在仓库根目录里跑）：

```powershell
# 终端 A：起试用档服务（公网档 + 专用试用库，端口 8030）
$env:PE_ENV = 'prod'
powershell -ExecutionPolicy Bypass -File scripts\trial.ps1 -Port 8030 -Reset

# 终端 B：把 8030 上那个服务接到公网上（⚠️ 请在同样设过 $env:PE_ENV 的终端里跑）
powershell -ExecutionPolicy Bypass -File scripts\tunnel.ps1 -Port 8030
```

链接从哪儿读：终端 B 的输出里，或仓库根的 `.trial\public-url.txt`。⚠️ **正常停止**（在它的终端里 `Ctrl-C`）时这个文件会被脚本自己删掉 —— 留一份写着死链接的文件比没有文件更坏；⚠️ 而**被硬杀**（IDE 的停止按钮 / 任务管理器 / 断电）时它可能**留下来**、而里面写着一条**已经失效**的地址 ⇒ 一律以我方最新通知为准，别照着一份旧文件去点。⚠️ 反过来，我方那台机器上的自检若发现链接可能已死，会往这个文件里**追加**几行说明（追加、不重写，所以上面那条链接还在）—— 看到那样的几行就是「这条链接已经死了，请找我方」。

⚠️ 若你们要**自己**开一条公网链接（而不是找我方），需要一个隧道工具 `cloudflared`：请只从它的**官方发布页**取（`https://github.com/cloudflare/cloudflared/releases`，文件名 `cloudflared-windows-amd64.exe`），并**照该页公布的 sha256 核对一遍**再放进仓库的 `tools\` 目录（⚠️ 核对方法、以及本仓那一份的核对结果见 spec §13.17.2）。⚠️ 随附的可分发包里**不含**这个 55 MB 的二进制 —— 隧道是我方这一侧的事。

### ② 同一个 WiFi 下的局域网链接（在机房、办公室里试用）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\trial.ps1 -Lan
```

跑起来之后终端会打印一条局域网链接，形状是 `http://<本机 IPv4>:8030/`（本机地址是脚本**现场数**出来的，不写死；换一次网络、或路由器重新分配一次，它就变了）。
⚠️ 同一个网段里**任何人**都打得开，而且是**明文 http**（口令与数据在网线上不加密）⇒ 只用于仿真数据。
⚠️ 「本机打得开、同事打不开」= Windows 防火墙挡了入站。终端会把该跑的那一条 `netsh advfirewall firewall add rule …` 原样打印出来（脚本**不会**自己去改防火墙），请以**管理员**身份跑一次；试用结束照它一并打印的 `delete rule` 删掉。
⚠️⚠️ **这一档必须留在「开发档」上**：如果你刚刚照 ① 在**同一个终端**里设过 `$env:PE_ENV = 'prod'`，那个设置会**留在这个终端里**（它不会自己消失），于是 `-Lan` 起出来的服务会发一枚「只有加密链接才收」的登录凭据 —— 而局域网链接是明文 `http`，浏览器会把它**丢掉**。症状很好认：**登录那一下是成功的，点下一个页面就说你没登录**。处置：换一个**新开的**终端跑上面那条命令；或在当前终端里先跑 `Remove-Item Env:\PE_ENV` 再跑它。（脚本自己会打印一大段 ⚠️ 说这件事，所以它不是悄无声息的。）

### ③ 在你们自己的机器上起一份

见随附的 `pe-ims-trial-<日期>.zip` 与它里面的 `README`。⚠️ 本文**刻意不描述它的内容、也不替它列前置条件**（那会与它自己那份 `README` 各说一套，改一处漏一处）—— 需要什么、怎么起，一律以包里的 `README` 为准。
⚠️ **建议解包到一个不含空格的目录**（例如 `D:\pe-ims\`，而不是 `D:\体育系统 试用\`）：本版本已经能在含空格的路径下起服务，而那条路径上要经过的第三方工具（压缩软件、Python 的包管理、机房里的安全软件）未必都能。
⚠️ **包里没有一份「锁定版本」的文件**：`python -m pip install -e backend` 装到的，是**你装的那一刻** PyPI 上满足 `backend\pyproject.toml` 那几条范围的**最新**小版本，可能比我方开发时用的更新（我方这边是 fastapi 0.141.1 / SQLAlchemy 2.1.3 / pydantic 2.13.5）。⚠️ 我方**实测过**更新的一档：在 fastapi **0.143.2** / SQLAlchemy **2.1.4** / pydantic **2.14.1** 上，接口契约 `/openapi.json` 与我方这边**逐字节相同**，而第 4 节那四条试用路线的**后端面全通**。⚠️ 那是**一次实测**、不是一条可以依赖的性质 —— 装完请照第 8 节自查一遍，有任何一格对不上就把终端原文发给我方。

## 4. 四条试用路线

⚠️ 下面每一步都在真机上逐步走过一遍。**会写数据的有四类**：每一次登录与登出、路线一第 6 步的提交打卡、路线一第 9 步的标为已读、路线二第 ⑥ 步的处置预警（试用后可一键重置，见第 7 节）；**其余全是只读**。⚠️ 路线一第 5 步那一次提交也**真发得出去**，只是被后端拒掉（409）、不写成一行。
⚠️ 文中那些数字取自**刚灌出来**的试用库；你们试用之后（处置过预警、标过已读）它们会变。

### 路线一 · 学生端（手机尺寸，学生自己看的那一份）

1. 打开链接 → 落在登录页。页面顶上一条告示：**「试用环境 · 数据为高保真仿真（60 名学生均为虚构） · 请勿录入真实学生信息」**（每一个页面都有它）。
2. 「我是」选**学生** → 学号填 `2023120001` → 口令填 `pe-demo-2025` → 点**登录** → 自动进到首页，顶上会话条显示「学生 2023120001 · 赵锦程」。
3. 看首页那几格：本周训练量 **108.0 分钟**（3 个动作）、本周打卡完成率 **100.0%**（3 / 3 个处方训练日）、待办 **0 项**、我的分层 **黄色层** + 一段判定理由（「短板 ≥2 项且体成分未判为异常（规则 Y3）」）、未读消息 **1** 条与电子勋章 **1** 枚。
4. 点底部导航**本周训练单** → 看见「这一周的七天」（训练日 3 天 / 休息日 4 天）与逐日逐动作的组次、每周量、动作代号；顶上一格是本周系数 **×1.00**（这一周不调整）。
5. 点**每日打卡** → 看见本周完成率与「我的打卡记录」14 行（标记列里 `demo` 的是仿真数据灌的，`迟交`、`休息日` 是服务端算的）。⚠️ 这一周（以及往前 14 天）每一天都已经有记录了，所以在这些天点**提交打卡**，请求会**真的发出去**、并得到一条**看得见的**提示：「`integrity_conflict · 409` —— 这一天（…）你已经打过卡了：一天只能有一行…」。**那是口径、不是坏了**（后端刻意不做「补卡覆盖旧行」，为的是「他当时交的是什么」在库里查得到）。
6. ⚠️ **想看见「成功」那一次**（建议给甲方演一下）：把「训练日 `log_date`」改成一个库里还没有记录的日期（例如往后两个月），「练了多少分钟」填一个数（**可以带一位小数**，例如 `30.9`），点**提交打卡** → 出现一个绿色的「**已打卡**」+ 服务端记下的时刻（⚠️ 那一句只挂**一两秒**就收起，之后留下的是三行常设格：「服务端记的 submitted_at」「服务端算的 late」「source / batch_id」；演示时请盯着看），「我的打卡记录」也多出一行（标记列写着 `checkin`；⚠️ 页面下方那句注释把这一档写成了 `student`，那是页面自己的笔误，我方已登记待修）。⚠️ 这一步**会写数据**（要回到干净状态请让我方重灌试用库，见第 7 节）。
7. 点**课堂快评** → 看见 0–10 的自觉受累量表（11 档，各配一句中文）与「我的课堂 RPE 趋势」4 次（均值 5.75 分）。⚠️ 课堂口令**只能手输**（照老师投屏上那一串），学生端读不到它 —— 那是用来挡住「猜一节课乱交」的。
8. 点**二次小测** → 看见本人 3 次小测（第 2 / 4 / 6 周的 30 秒深蹲与 20 米折返）与**班内百分位**（教学班 2：折返班内百分位 98.3、班内名次第 1 / 30；教学班 4：92.5、第 2 / 20）。
9. 点**消息中心** → 看见站内消息（这个学生有 1 条未读「本周电子勋章」）；点**标为已读** → 那一格从「未读 1 / 1」变成「未读 0 / 1」。

### 路线二 · 教师端（含闭环那一步）

1. 登出，「我是」选**教师 / 管理员** → 工号 `T0001` + 同一口令 → 落到班级大屏。
2. 顶部报头写着「**我任教的 2 个班 / 50 人次**」，班次标签只有 `1 · 行政班01`、`2 · 提升班` 两个（别的班不在这里）。
3. 点**班级周报** → 「教学班（只列我任教的）」下拉里只有那两个班；看见算法建议「维持当前强度」、① 分层分布（红 3 / 黄 17 / 绿 10，名册 30 人）、② 人均课堂 RPE **6.37**（环比 +0.10）、③ 三层完成率（红 50.0% / 黄 62.7% / 绿 55.0%）、④ 进步榜。
4. 点**预警队列** → 顶上一行是「共 21 条 · 红 9 / 黄 4 / 绿 8 · 待处理 21 / 已处理 0 / 已忽略 0」；页面自己写明范围是「我本学期任教班级的学生（**不是全校**）」，管理员登录看到的才是全校。
5. 点某一条预警里的学生名 → 进到**学生详情**：当前分层 + 可解释性展开、本周训练单（含减量与理由）、班内百分位、他的预警、他的今日。
6. ⚠️ **这一步会改数据。** 回到预警队列，在第一条红色预警（「课堂 RPE 连续 3 次 ≥ 9 分」· 周晨阳 #1）上点**减量 20%** → 卡片下方出现「**✓ 减量 20% 已提交 · STATUS → 已处理**」与「**站内消息：✓ 已推给学生**」，顶上那一行变成「待处理 20 / 已处理 1」，这张卡的「处置痕迹」写上「减量 20% · <时刻>」，三个按钮随之消失（一条预警只能处置一次）。
7. 登出 → 用学生 `2025060001`（周晨阳）登录 → 点**消息中心** → **多出一条**「本周训练量已减 20%」，正文是「老师看过你的预警（RED_RPE_SUSTAINED）之后给本周减了量：本周训练单的系数是 0.80…打开『本周训练单』看到的就是这个量」。**这就是闭环**：教师点一下，学生的消息中心当场多一条、那条预警的状态与顶上的计数也当场变。
8. ⚠️ **而这一周的训练单系数通常「本次未再减」** —— 点开那张预警卡，下方会出现「本次**未再减**」这四个字，**那是页面自己会显示的、不是坏了**。理由是：系统在预警**落库的同一批**里就已经自动减过 20%（系数已经是 0.80），而一处方一周**至多一条**这样的自动调整，所以老师再点一次不会把它减成 0.64（那会是一次没人知道发生了的连乘）。⇒ 演示库上**每一条红色预警都是这个形状**（那 9 个学生都已经有一条自动调整），点哪一条都一样。要看「系数真的再变一次」，请让我方换一份没跑过自动管道的库。

### 路线三 · 管理台

1. 用 `T0003` 登录 → 直接落到**资源目录**：23 个资源一格一格列着，每格标着「可写 / 只读」与删除策略；页面自己写明「写仅管理员」（普通教师与学生看不到新建 / 编辑 / 删除按钮，不是禁用、是不出现）。
2. 点**学生**那一格 → 分页表「1–20 / 共 60 行」，列是 id / 学号 / 名称 / 性别 / 年级 / 院系 / 操作。
3. 点某一行的 **id**（一个链接）→ 资源详情页：逐列列出这一行（含出生日期），上面有「✎ 编辑」「← 列表」「目录」。⚠️ 23 个资源里只有 **9 个可写**，其余 **14 个只读**（例如体测成绩、分层结果、动作库、处方模板 —— 页面上会写明为什么不给改）。
4. ⚠️ 第 3 步落在**资源详情页**上，那一页没有「审计留痕」这一格：先点它上面的**目录**回到资源目录，再点**审计留痕** → 一张**只读**表，最新在前，九列（行 id / 时刻 / 身份类型 / 身份 id / 工号 / 方法 / 路径 / 状态码 / 对象）。⚠️ 它只记写操作：**忠实**走完本文四条路线之后实测 **13 行**，**全部是 `POST`（登录、登出、提交打卡、标为已读、处置预警），一行 `GET` 都没有** —— 见第 6 节须知 ③。

## 6. 须知（**开始试用之前请先读完这一节**）

下面四条排在最前面，因为它们最容易出事：

**① 数据是仿真的，请勿录入真实学生信息。** 每一个页面顶上那条告示就是这个意思。这套系统今天没有接任何真实数据源，也没有为真实数据做过隐私与合规处置；把真学生的体测数据敲进来，等于把真数据放进一个**公开可达**的演示环境。

**② 公网链接是公开可达的、口令是公开的、没绑口令的账号会被抢绑。** 任何知道那条地址的人都能打开（地址是随机发的，而**随机不等于鉴权**）；演示口令是公开的，任何人都能登任何账号（含管理员）；**还没绑口令的账号可以被别人抢先绑走** —— 绑定材料是「学号 + 出生日期」/「工号 + 姓名」，而任何在册教职都读得到全校名册（含出生日期）。⇒ 试用期间不要在这套系统里放任何真东西；正式部署要换成不可猜的验身材料（一次性绑定链接 / 校园卡后台校验）。

**③ 读操作不留痕，写操作全部留痕。** 「谁翻过哪个学生的健康档案」今天在库里**查不到**（读操作一律不记）；而登录、绑定与每一次写（新建 / 修改 / 处置预警 / 标为已读）都记一行，管理员在**审计留痕**页看得到（那张表只读，连改都改不了）。

**④ 试用库可以一键重置**（见第 7 节）：你们试用时写进去的一切都会被冲掉，回到干净的 60 人仿真库。

另外四条（技术细节与后续要做的事；逐字口径见 **spec §13.15**）：

**⑤ 连续输错口令会被锁。** 同一个学号 / 工号连错 **5** 次会被锁 **15** 分钟（首次绑定那一侧是 3 次锁 60 分钟），而**被锁时页面的提示与「口令错」一模一样**（这是刻意的：不告诉撞库的人「这个账号存在」）。⇒ 试用时若有人反复试口令，请等 15 分钟，或让我方重置；⚠️ 反复重输**不会**把锁推后。⚠️ 这几个数都是服务端可配的，逐字口径与唯一所有者见 spec §13.4.6（本文是一份时点快照）。
⚠️ 而**页面上刻意不写这几个数字**（登录页、页脚与那句 401 的提示都只说「连错多次会被临时锁定，稍后再试」）：写在页面上就成了第二个所有者，改一处漏一处。

**⑥ 接口文档是公开的。** `<链接>/docs`（与 `/redoc`、`/openapi.json`）任何人都能打开。它是本原型作为「技术对接依据」的载体，故刻意保持公开；若你们要求收到内网，处置是在反向代理那一层加一层认证或 IP 白名单。

**⑦ 四张表只增不减（⚠️ 清理作业**有了、而它不会自己跑**），备份是明文的。** 审计留痕（含**读**审计）、登录尝试、会话记录自 2026-10-17 起**有了**清理作业：`backend\scripts\retention.ps1`（先加 `-DryRun` 看一遍「将删多少行」、去掉它就真删；⚠️ 删的是**过期**行，四个保留窗口各有一个下界）。⚠️ 而它**不会自己跑** —— Windows 上没有 cron，要它每天夜里自动跑，请照 `backend\scripts\register_retention_task.ps1` **打印**出来的那一条命令自己注册一个计划任务（它刻意不替你注册）；口径正文在 spec **§13.24**，给开发者的一句话在包里的 `README`。⚠️ 备份那半格**没变**：仍然是整库备份、是一份**明文**的数据库（里面是全部学生的健康档案），可以指定落到别的盘（例如加密卷），也**不会**自己删旧备份；⚠️ 而清理**不会**替你自动备份，要留后路请先跑一次 `backend\scripts\backup.ps1`。

**⑧ 降过权的管理员要重新登录才在界面上生效。** 把某人从管理员降成教师之后，他手上那张会话在重新登录之前仍然会被送进管理台（目录照样渲染），而管理台那 23 个资源的读写与审计留痕页会吃一个「不是管理员」的拒绝（权限本身是**立刻**生效的 —— 失效方向是少给权限，是安全的那一侧）。⚠️ 而**不是每一次读**：`学生` 与 `教师` 那两行走的是另一道闸门（「任何在册教职」），降权之后**仍然读得到全校名册（含出生日期）**。处置：让他登出重登。

⚠️ spec §13.15 一共 **11** 条，本文挑了其中 **8** 条（第 2、3、4、5、6、7、8、10 条，合并重写成上面 ②③⑤⑥⑦⑧ 与 ① 的一部分），另加「试用告示」与「一键重置」两格。**没有挑的三条是给开发者与运维的**：产品档的环境变量与跨域白名单怎么设（第 1 条）、换数据库后端之前要先做哪两件事（第 9 条）、自动化测试覆盖率那三个口径怎么读（第 11 条）—— 需要时请直接读 spec §13.15。

## 7. 数据是仿真的、怎么重置

试用库是仓库里一个单独的文件（`backend\pe_trial.db`），与开发用的演示库分开。**重置 = 删掉它重灌一份**：

```powershell
# ⚠️ 先停掉正在跑的那个服务（在它的终端里 Ctrl-C），否则脚本会报一句「正被别的进程持有」并停下（它不硬删）
powershell -ExecutionPolicy Bypass -File scripts\trial.ps1 -Reset
```

它会删掉旧库（删之前先打印路径、字节数与指纹）、重新灌一份 60 人的仿真库、再把服务起在 8030 上，终端里会打印链接与账号。
⚠️ **重置会丢掉你们试用时写进去的一切**：绑过的口令、打的卡、交的快评、处置过的预警、标过已读的消息，全部回到刚灌出来的样子。
⚠️ 同一天里反复试用**不需要**每次重置：不带 `-Reset` 跑同一条命令会**复用**现有的库。

## 8. 出问题怎么自查（四步）

1. **链接打不开** → 公网链接的寿命等于我方那个隧道进程的寿命。⚠️ 失效有**两种样子**：打开是一页英文错误（Cloudflare 自己的），**或**浏览器直接说「找不到服务器」—— **两档都是链接已失效、都不会自己恢复**，都要找我方重开一条（重开之后是一条**全新的地址**，请重新发给试用的人）。⚠️ 找我方之前先排除你们自己这一侧：换一个网络、或换一台机器打开**同一条**地址，若两样都打不开就是我方那一侧。
2. **登录没报错，可下一个页面就说没登录** → 这是「档位与 https 不匹配」：明文 http 的链接与公网 https 的链接在服务端要用两套不同的设置（一个叫 `PE_ENV` 的环境变量）。⚠️ **谁能改，分三档**：**我方给的那条公网链接**（§2①）你们改不了、请找我方；**机房里自己起的局域网那一份**（§2②）与**你们自己机器上解包起的那一份**（§2③）都能自己改 —— 起服务的那个终端里会打印一段 ⚠️，逐字写着处置（大意是：明文 http 上请把 `PE_ENV` 去掉、回到缺省档，或者去掉 `-Lan`）。
3. **会话条上写着「身份未确认…」** → 它最多等 **10 秒**，之后会自己改口成「身份确认超时：10 s 内 GET /api/auth/me 没有回答（后端或反向代理挂住了）。请刷新页面重试」并给一个刷新入口 → 点它刷新即可。（⚠️ 顶上那条「试用环境」告示**可能晚十几秒才出现**，不是没挂：它要等两个后台请求**依次**回来，而这两个请求都要穿过公网隧道。我方实测落在 **1 秒到 13 秒**这个区间里的多档（2026-10-15 一次是单次隧道往返 5.6–6.3 秒 ⇒ 告示最坏约 11–13 秒；2026-10-16 两次分别是 2.0 秒与 3.8 秒）—— 这条通道的快慢会随时间漂移，**没有稳定上界**，故本文刻意不给一个可以依赖的数。⚠️ 在它挂上之前**也请勿录入真实学生信息** —— 这套系统今天没有接任何真实数据源。）

4. **页面上一片空 / 说没有训练单 / 说这一周没有数据** → 看会话条上那个**日期**（它叫「业务日」）：整套仿真数据是按 **`2025-10-12`** 那一天造的，而那个输入框缺省也正是这一天。⚠️ 把它改成今天会让**学生端那两块当场空掉**（首页说「本周还没有训练单」、训练单页说「没有训练单」并给一条 `no_active_prescription · 404`）—— **那是口径、不是坏了**。改回 `2025-10-12` 就都回来了。⚠️ 而**班级周报不受它影响**：那一页读的是「存下来的那一份」（只在周日生成）、周次缺省是「最新一份」，故改了业务日它照样把上一份周报显示出来。⚠️ 它记在**浏览器本地**，所以换一台机器、换一个浏览器、或清过一次浏览器数据，都要重新设一次。

还不行就把这三样发给我方：**链接**、你用的**账号**、页面上那句**原文**。
