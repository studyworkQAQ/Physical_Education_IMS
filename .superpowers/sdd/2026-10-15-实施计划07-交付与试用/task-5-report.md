## ⑤ R3 · `cloudflared.exe` 的 sha256 与官方 checksum 的独立比对

### 从哪儿取的、取到没有

**取到了**，而且是从**本机**直接取的（不是二手转述），两个官方页面各命中 2 处、逐字相同：

| 源 | 怎么取 | HTTP | 字节 | `cloudflared-windows-amd64.exe` 的 sha256 |
|---|---|---|---|---|
| **官方** release 页 | `https://github.com/cloudflare/cloudflared/releases/tag/2026.10.0` | **200** | 200 740 B | `86aee4017b26625cee8484c113558f48effa4cd47f7aa05fcf425604e5d2b23c` |
| **官方** 资源清单 | `https://github.com/cloudflare/cloudflared/releases/expanded_assets/2026.10.0` | **200** | 108 872 B | 同上（命中 **2** 处，两处逐字相同） |
| **本机** 仓库里那一个文件 | `Get-FileHash tools\cloudflared.exe -Algorithm SHA256` | — | **55 365 048 B** | `86AEE4017B26625CEE8484C113558F48EFFA4CD47F7AA05FCF425604E5D2B23C` |

取法（PS 5.1，可复现；⚠️ 第一行是承重的 —— 5.1 的 .NET 缺省只谈 TLS 1.0/1.1）：

```powershell
[Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12
$r = Invoke-WebRequest -Uri 'https://github.com/cloudflare/cloudflared/releases/expanded_assets/2026.10.0' -UseBasicParsing -TimeoutSec 60
[regex]::Matches($r.Content, 'cloudflared-windows-amd64\.exe.{0,4000}?([0-9a-fA-F]{64})') | ForEach-Object { $_.Groups[1].Value }
```

⚠️ **出网间歇性失败，如实记**：本波第一次走 `api.github.com/repos/cloudflare/cloudflared/releases/tags/2026.10.0`
撞上 **`API rate limit exceeded for 38.45.155.89`**（未鉴权的 REST 限额），换成上面那两个**页面** URL 就通了。
⚠️ 另一格如实记：本波先用 IDE 的网页抓取取过一次同一份清单，⚠️ 而它回的内容与 URL 之间的对应关系
在本波这一侧**不可核**（三次不同 URL 回了同一份内容）⇒ 最终**采信的是本机 `Invoke-WebRequest`
那两次**（状态码、字节数、命中处数都是本机量的）。

### 比对结果

⇒ **相符**（大小写不敏感地逐字相同）。⚠️ **不是 Critical**：不需要报控制者、不需要停用那个二进制、
